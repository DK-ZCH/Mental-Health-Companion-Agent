| # | 事实 | 对设计的约束 |

## 四、文章结构模板（D2 相关，纯文本固定骨架）

```text
【域标签】标题（≤ 30 字）

（首段：2–3 句话的摘要式开头，说明「这篇讲什么、适合谁」）

一、小节标题
（段落，2–4 句；术语首次出现给一句白话解释）

二、小节标题
……

三、小结：可以带走的三点
（三条短句，不编造统计数字）

——
（固定结尾块，逐字使用 D5 批准的免责与求助指引；无任何号码）
```

| 项 | 约束 |
| --- | --- |
| 字数 | **800–1200 字/篇**（正文含小节，不含标题行）|
| 格式 | **纯文本**；小节用「一、二、三、」；空行分段；**无 #/*/``` 等标记** |
| 标题 | `varchar(200)` 内，实际 ≤ 30 字 |
| 语言 | 简体中文，面向大学生；第二人称称呼用「你」 |
| cover_url | 全部留空（无图素材，不编造图片）|

## 五、内容边界（硬约束 · 违反任意一条即不合格）

| ❌ 禁止 | 说明 |
| --- | --- |
| 诊断/确诊用语 | 不写「你患有抑郁症」；只描述普遍体验与一般性建议 |
| 药物 / 剂量 / 治疗方案 | 完全不涉及；就医决策归专业机构 |
| 自伤方法的任何描述 | 含「流传的说法」也不转述 |
| 未经核实的号码 / 热线 / 机构名 | 沿用 Round 3 Q2：**无号码原则延伸到文章** |
| 编造统计 / 文献 | 不写「研究表明 73%…」；**无来源就不写数字** |
| 对具体个人的评价 | 不做任何「你有问题」式断言 |

| ✅ 必须包含 | 说明 |
| --- | --- |
| 固定免责句（D5 批准后逐字使用） | 每篇结尾块第一行 |
| 无号码求助指引 | 与 Round 3 卡片措辞一致：就近急诊 / 不要独处 / 信任的人 / 学校心理中心（若提供）|
| 去污名化基调 | 求助是正常行为；不说「软弱」「矫情」 |

> **作者身份纪律**：内容由本助手起草、**用户逐篇审核后入库**；
> 文章**不署任何专业头衔/作者名**（不冒充医生或机构）。

## 六、验收标准（逐篇质量闸门 + 语料级闸门）

### 逐篇（8 项，全部通过才算合格）

| # | 闸门 | 核验方式 |
| :-: | --- | --- |
| 1 | 字数 800–1200 | 脚本统计 |
| 2 | 纯文本（无 `#` `*` `-` 列表符 / HTML 标签 / ```） | 正则扫描 |
| 3 | 骨架完整：首段 + ≥3 个「一、二、…」小节 + 「小结」+ 结尾块 | 结构检查 |
| 4 | 含 D5 批准的**固定免责句**（逐字） | 字符串匹配 |
| 5 | 禁止项正则扫描：诊断词（确诊/患有/服药…）、药物名、**任何数字号码模式**、百分比统计 | 正则扫描 |
| 6 | 术语首现有白话解释 | 人工（评审时）|
| 7 | 与同域另一篇主题互补不重复 | 人工 |
| 8 | 标题 ≤ 30 字且带域标签 | 脚本 |

### 语料级（3 项）

| # | 闸门 | 标准 |
| :-: | --- | --- |
| 9 | 覆盖 | 6 域 × 2 篇全部就位 |
| 10 | 去重 | 标题全局唯一；任意两篇首段不同 |
| 11 | **RAG 就绪（规模门槛）** | 总字数 ≥ 10,000；每篇可独立成段检索；每篇首行含域标签 |

> **⚠️ 表述纪律（用户 2026-11-03 冻结）**：**≥10K 字是 RAG 开始设计的最低规模门槛，
> 而非内容质量充分条件。** 质量闸门 = 数量 + 主题覆盖 + 篇间互补性 + 可检索性 +
> 事实可靠性 + 安全边界 —— 报告中必须按此完整表述，禁止写成「超过 10K 即合格」。

> 核验由我以**临时脚本**执行并出报告（不进仓库，不属应用代码，不破坏 Step ⑥「零代码」性质）。
