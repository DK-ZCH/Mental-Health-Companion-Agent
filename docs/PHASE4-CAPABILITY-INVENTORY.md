## 七、建议（三档）

### A · 收口（推荐）

```text
不做 Round 5 新能力，改为一个「工程收口小批」：
① Observability：每次请求记录 tool 名 + 单工具耗时 + 成功/失败（不含参数与内容）
② 对外叙事：README / 简历口径统一（按 §5.1 / §5.2）
```

- 成本：小（1 个拦截/包装层 + 日志字段 + 测试）
- 可验证：✅ 可断言日志/trace；可变异（删记录 → 测试红）
- 零前端、零新依赖

### B · Memory

需要 `conversationId` + 会话存储 + 前端会话 UI，且「是否记住」难验证。**不建议现在做。**

### C · RAG

`knowledge_article` 只有 5 条 7 字符占位内容。**先做内容建设，否则只能证明“会调向量库”。**
